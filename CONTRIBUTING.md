# Contributing to PrivateReceive

Thank you for your interest in contributing.

## Project Stage

This project is in early development. We are currently focused on building the core guided toolkit and operational playbooks.

## How to Contribute

At this stage, the most useful contributions are:

- Feedback from people working with nonprofits or activists in high-risk environments
- Suggestions for improving clarity of guides and recovery procedures
- Testing of workflows once early versions are released
- Improvements to documentation

## Getting Started

1. Review the main repository: [privatereceive](https://github.com/PrivateReceive/privatereceive)
2. Review the playbooks repository: [playbooks](https://github.com/PrivateReceive/playbooks)
3. Open an issue to discuss ideas before submitting major changes

## Pull Requests

- Keep changes focused and well-described
- Follow existing code and documentation style
- Ensure any new content remains clear for non-technical users

## Code of Conduct

Please note that this project follows a [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold it.
