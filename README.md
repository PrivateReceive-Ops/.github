### PrivateReceive

Guided open-source tools that help nonprofits and activist groups safely receive Bitcoin privately and manage organizational funds under financial repression.

**Main repositories**
- [privatereceive](https://github.com/PrivateReceive/privatereceive) — Core toolkit
- [playbooks](https://github.com/PrivateReceive/playbooks) — Operational security & recovery guides

**Focus**
- Private receiving workflows
- Simple multi-signature (2-of-3) setup and recovery
- Designed for non-technical users in high-risk environments

**Status**  
Early development. Building foundations and preparing for pilot organizations.
