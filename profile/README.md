# PrivateReceive + Threshold Ops

**Guided open-source tools that help nonprofits and activist groups safely receive Bitcoin privately and manage organizational funds under financial repression.**

## The Problem

Nonprofits and human rights groups operating in repressive environments frequently face frozen bank accounts and financial surveillance. When they turn to Bitcoin, two critical failures often occur:

1. Staff reuse addresses, creating surveillance risk.
2. Multi-signature setups are too complex for non-technical users — especially when devices are seized or team members become unreachable.

Most existing tools and guides assume technical comfort and calm operating conditions. This project is built for the opposite reality.

## The Solution

PrivateReceive + Threshold Ops is a tightly scoped toolkit focused on two capabilities:

- **Private receiving workflows** with strong defaults against address reuse
- **Opinionated 2-of-3 multi-signature setup and recovery** designed for non-experts under threat

The project prioritizes clear guidance, recovery procedures, and high-risk operational security over maximum flexibility or advanced features.

## Project Status

This project is in early development.  

We are currently preparing the foundation and seeking pilot organizations. Code and documentation will be published here as development progresses.

## Planned Approach

**Phase 1 (Months 1–3)**  
- Guided multi-signature setup and recovery wizard  
- Practical private-receiving workflows  
- Minimal organizational dashboard  
- Operational playbooks  
- Setup and recovery drills with pilot organizations  

**Phase 2 (Months 4–6)** – only after Phase 1 validation  
- Strengthened Silent Payments support where mature  
- Refined recovery procedures based on pilot feedback  
- One additional language based on demand  

## Who This Is For

Non-technical staff and treasurers of:
- Nonprofits
- Activist groups
- Independent media

…operating under financial repression or heavy surveillance.

## Principles

- Open source by default
- Designed for non-experts
- Threat-model aware
- Prefer reliable foundations over premature complexity
- Success = users can complete critical workflows
